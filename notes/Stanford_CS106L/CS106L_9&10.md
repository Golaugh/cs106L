现在我们了解了 [类之间的关系和如何去重载函数](CS106L_7&8) ，似乎构建复杂的抽象类已如呼吸一样简单！然而基米在摆弄 .h 文件时意识到了一点：类中的函数在遇到不同类型的传参时我们大可以多写几个构造函数。但要是类本身需要处理不同类型的参数，岂不是要一个个创建 .h 文件，不过不要慌，我们有:
`template <typename T>`

只要将这个小玩意放在类的上面并将想灵活化的类型替换为 T，在声明类的时候就会根据传入的类型自动推导出对应的类：
![[1.png]]

但是在这里我们要明白 Template 和 Type 的区别，比如 `Vector<double>` 和 `Vector<int>` 这两个实例，它们都是 `Vector` 的 Template，但是是不同的 Type。所以作为参数传入类时并不相同。实际上在使用 `template <typename T>` 的时候，我们还可以任意增加其它的参数或者修改这个参数，比如:
`template <size_t N>` 和 `template <bool B>` ，只要在声明的时候在对应位置给出参数即可。

然而在使用 Template 的时候，还有一些规则要遵循：
	在 .cpp 中实现模版类，也一定要加上 `template <typename T>`
	在 .h 底部还要包含使用了该模版的 .cpp 文件，而 cpp 不再需要 `#include`
	typename 可以直接与 class 进行互换

不过原因也很直观，在 main 中我们使用 `const Vector<int>& v` 来约定 v 内部数值不会被改动，但是编译器并不知道 printVec 里面的 `.size()` 和 `.at()` 是否会改动数值，所以我们要在 .h 文件和函数实现的 .cpp 文件里对应函数后面加上 const。实际上，在标明 const 的函数里使用 this，其会带上 const 属性，而要是在创建类的时候使用 const，其私有变量默认为 const，且只能使用同为 const 的成员函数。

在 python 中，我们使用 list 时可以直接 `list_1[i]` 来获取对应位置数值，还能 `list_1[i] = 11` 来直接进行改变，这对于 cpp 编译器是不可想象的事情！在上文中我们使用了 `T& at(size_t index) const` 。然而因为返回值没有 const，我们仍然可以使用 at() 对内部数值进行修改，可是要是返回值加上了 const，我们就无法使用 at() 进行重新赋值了。所以我们需要实现**两版** `T& at(size_t index)`，这也叫做 const 重载。

既然类都可以写成 Template 了那么函数自然也不例外，一个经典的 Template 函数：
```
template <typename T>
T min(const T& a, const T& b) {
	return a < b ? a : b;
}
```

但是具体传入参数的情况多种多样，简而言之：
	如果传入参数类型确定且相同，使用隐式实例化 `min(106, 107)`
	想明确传入类型，使用显式`min<int>(106, 107)`
	如果想传入不同类型，则需要`<typename T, typename U>` 按位置划分
	遇事不决就 auto！开玩笑的一般只针对不确定的返回值类型
